# Player props model: method and backtest

Auto-generated by `python -m futball.props.backtest`. Inputs: ESPN box scores for the 2026/27 season in progress (820 finished matches, 2675 players; latest 2026-11-02).

## Method

- **Rate**: goals / assists / shots on target per full-game equivalent (a start = 1, a substitute appearance = 0.3, because free box scores carry no minutes), shrunk toward the position average with prior strengths 6 games (goals), 8 (assists), 3 (SOT).
- **Exposure**: P(start) = 60% last five team matches + 40% season share, x0.3 if absent for 3+ team matches; non-starters add a substitute chance x0.3. Goalkeepers and players under 2 appearances / P(start) < 25% get no row.
- **Team factor**: the player's rate is scaled by (this match's expected team goals or SOT) / (the team's shrunk season average). Production uses the match model's expected goals and SOT; the backtest uses an opponent-concession proxy because no match model exists for past dates.
- **Probability**: Poisson for goals and assists; negative binomial for SOT with the dispersion tuned below.
- **Not modelled**: penalty-taker status, set-piece roles, injuries/suspensions beyond the absence heuristic, minutes, tackles (no free source has them).

## Backtest
